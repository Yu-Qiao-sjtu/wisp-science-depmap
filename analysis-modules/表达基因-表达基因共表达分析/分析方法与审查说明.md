# 分析方法与审查说明

## 1. TM00 原型

原始脚本读取脚本 01 清洗得到的 `ccle_exprSet.rds`。矩阵行为细胞系，列为表达基因，值为表达量。它执行：

1. `cor.test(FOXA1, ESR1)`，验证单个基因对。
2. 固定 `ESR1`，逐列执行 `cor.test(ESR1, gene)`。
3. 保存 `Gene1`、`Gene2`、`cor` 和 `pvalue`。

原型没有癌种分层，也没有多重检验校正。

## 2. 26Q1 全局实现

`04_build_global_correlation_matrices.R --dataset expression`：

1. 读取蛋白编码基因表达矩阵。
2. 保留 `IsDefaultEntryForMC == "Yes"`，并按 `ModelID` 去重。
3. 对 19,215 个基因进行两两 Pearson 相关，观测维度为 1,719 个细胞系。
4. 使用 `pairwise.complete.obs` 处理缺失值。
5. 每 128 个源基因保存一个未压缩 RDS block。

结果保存 `correlation` 和 `pair_n`。它完整覆盖原型中的 `FOXA1–ESR1` 与 `ESR1–全部基因`，并扩展为任意表达基因对。全局结果没有直接保存 P 值或 FDR；有相关系数和样本数时可以重新计算 P 值。

## 3. 癌种谱系内实现

`17_build_lineage_sparse_networks.R --families expression_correlation`：

1. 使用 `Model.OncotreeLineage` 对细胞系分组。
2. 仅分析至少有 10 个样本的谱系。
3. 每个谱系内，对每个源基因检验全部目标表达基因。
4. 排除自身相关后，每个源基因保留正相关 Top 100 和负相关 Top 100。
5. 保存相关系数、共同样本数、P 值、BH FDR、正负方向排名和绝对值排名。
6. 对完整结果生成互惠基因对。

癌种内结果是稀疏网络。未出现的基因对表示没有进入该源基因的 Top 100，并不表示相关系数为零或未经计算。

## 4. 结果解释边界

- 全局相关可能受到癌种组成影响；某个关系可能反映两个基因都在同一类癌种中高表达。
- 癌种内分析减少癌种组成混杂，但样本量较小，相关系数更不稳定。
- 大样本会使很小的相关系数也达到统计显著，筛选时需要同时查看效应量、FDR、样本数及跨谱系稳定性。
- 共表达只能提供关联证据，不能证明因果、直接调控或蛋白相互作用。
- 当前 26Q1 输入和 TM00 旧版输入的发布版本及样本集合不同，因此属于方法覆盖和升级，不应宣称数值逐项复现旧结果。

## 5. 不属于本模块的相邻结果

以下结果虽然也包含“相关”或“基因网络”，但不是表达基因—表达基因共表达：

- `effect_correlation`：CRISPR Gene Effect 基因—基因共依赖。
- `expression_dependency`：表达基因—CRISPR 依赖靶基因。
- `wgcna_dependency`：围绕依赖性构建的 WGCNA 模块。
- `prism_auc_expression_correlation`：药物 AUC—基因表达相关。
