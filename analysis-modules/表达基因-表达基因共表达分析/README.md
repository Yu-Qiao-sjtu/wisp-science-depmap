# 表达基因—表达基因共表达分析

## 模块目的

本模块分析不同细胞系中两个基因的表达量是否协同变化。Pearson 相关系数描述共表达的方向和强度：正值表示两个基因倾向于同时升高，负值表示一个升高时另一个降低。相关关系可用于发现共同调控、共同通路或蛋白复合物候选，但不能单独证明直接调控或物理相互作用。

## 与 TM00 的关系

TM00 第 02 号脚本是本模块的原型：先验证 `FOXA1–ESR1`，再固定 `ESR1` 扫描全部表达基因。当前 26Q1 实现将其扩展为所有表达基因两两相关，并增加癌种谱系内分析。

```text
TM00-02：FOXA1–ESR1；ESR1 × 全部基因
    ↓
26Q1 全局：19,215 × 19,215 个表达基因
    ↓
26Q1 癌种内：每个合格谱系分别计算，按源基因保存正/负相关 Top 100
```

## 模块组成

| 目录/文件 | 内容 |
|---|---|
| `scripts/02_gene_gene_correlation.R` | TM00 原型脚本 |
| `scripts/04_build_global_correlation_matrices.R` | 26Q1 全局完整矩阵生成脚本；其中 `dataset=expression` 属于本模块 |
| `scripts/17_build_lineage_sparse_networks.R` | 癌种内稀疏网络生成脚本；其中 `family=expression_correlation` 属于本模块 |
| `scripts/18_verify_lineage_sparse_networks.R` | 癌种内相关结果数值抽查脚本 |
| `scripts/22_finalize_lineage_networks_server.R` | 服务器端覆盖率和结构验收脚本 |
| `scripts/脚本来源.md` | 原始脚本位置与快照 SHA-256 |
| `data/输入数据清单.md` | 输入文件、筛选条件和数据结构 |
| `results/结果数据索引.md` | 180G 知识库中对应产物、大小和字段 |
| `分析方法与审查说明.md` | 计算逻辑、覆盖关系和审查限制 |
| `module.intent.json` | 供 agent 路由使用的模块、模态、关系、范围和样本口径标签 |
