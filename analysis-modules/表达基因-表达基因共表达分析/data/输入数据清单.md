# 输入数据清单

服务器模块目录保存完整 26Q1 表达输入和 `Model.csv`；本地文档目录只记录其来源和结构。

| 阶段 | 输入 | 结构/用途 |
|---|---|---|
| TM00 原型 | `TM00/DepMap_TM00/output/ccle_exprSet.rds` | 行为公共细胞系，列为与 Gene Effect 对齐后的基因；供 ESR1 扫描使用 |
| 26Q1 全局及癌种内 | `data/OmicsExpressionTPMLogp1HumanProteinCodingGenes.csv` | 蛋白编码基因表达矩阵；筛选默认模型后为 1,719 个模型、19,215 个基因 |
| 26Q1 癌种内 | `data/Model.csv` | 使用 `ModelID` 对齐，并用 `OncotreeLineage` 划分癌种谱系 |

## 数据筛选

- 表达矩阵仅保留 `IsDefaultEntryForMC == "Yes"`。
- `ModelID` 去重，每个模型只进入一次计算。
- 基因列名移除末尾括号中的 Entrez ID，使用纯 gene symbol。
- 癌种内分析通过 `ModelID` 将表达矩阵与 `Model.csv` 对齐。

## 原始位置

本地脚本默认以 `--project-root` 指定 DepMap 工程根目录，并从其 `data/` 子目录读取 26Q1 文件。180G 知识库中的结果位于服务器工程的 `knowledge/depmap-26q1-full/` 下。

服务器实体输入位于本模块 `data/OmicsExpressionTPMLogp1HumanProteinCodingGenes.csv` 和 `data/Model.csv`。表达文件 SHA-256 为 `0377be80c525fde98cbd2c6e8b06bdf2a4014a9683eb70182c1f8649d711021a`。该文件是当前本地保留的 26Q1 输入副本；它筛选出的模型集合与已落盘表达矩阵的冻结 `sample_order.csv` 存在版本差异。复现当时计算的样本集合时，应以结果目录中的 `sample_order.csv` 为准。
