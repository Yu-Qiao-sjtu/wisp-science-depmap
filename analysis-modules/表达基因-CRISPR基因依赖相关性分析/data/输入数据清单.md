# 输入数据清单

本模块同时使用表达量、CRISPR Gene Effect 和 Model 注释。服务器模块目录通过软链接引用前两个已整理模块中的同一份输入实体，避免重复保存约 746 MiB 数据。

| 输入 | 数据结构 | 用途 |
|---|---|---|
| `OmicsExpressionTPMLogp1HumanProteinCodingGenes.csv` | 行为测序/模型记录，基因列为 `log2(TPM + 1)` | 表达源矩阵；保留 `IsDefaultEntryForMC == "Yes"`，按 `ModelID` 去重 |
| `CRISPRGeneEffect.csv` | 行为 `ModelID`，列为基因，值为 CRISPR Gene Effect | 依赖靶矩阵 |
| `Model.csv` | 每个模型的注释与 `OncotreeLineage` | 癌种内分层 |

## 共同样本口径

全局脚本取默认表达模型与 Gene Effect 模型的 `ModelID` 交集，共 1,140 个细胞系。全局表达共表达模块可以使用 1,719 个表达模型，纯 Gene Effect 共依赖模块可以使用 1,208 个 Gene Effect 模型；本模块必须同时具有两种测量，因此不能直接使用任一单模态的全部样本。

癌种内脚本进一步与 `Model.csv` 的 `OncotreeLineage` 对齐，并在每个谱系内计算。当前 24 个完整谱系的样本数范围为 10–120。
