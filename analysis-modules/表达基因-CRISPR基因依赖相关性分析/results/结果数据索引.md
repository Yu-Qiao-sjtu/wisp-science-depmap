每个全局 block 是一个 R list：

| 字段 | 类型/含义 |
|---|---|
| `schema_version` | 整数，当前为 1 |
| `source` | `expression` |
| `target` | `CRISPRGeneEffect` |
| `source_start`, `source_end` | 该块在表达源顺序中的范围 |
| `correlation` | 数值矩阵，行=表达源、列=依赖靶 |
| `pair_n` | 整数矩阵，每个组合实际使用的完整观测数 |

抽查首个 block：`correlation` 与 `pair_n` 均为 `128 × 18,531`；`pair_n` 实际范围为 4–1,140，因此读取全局结果时必须检查样本数，不能只按相关系数绝对值排序。全局结果没有预计算 `p_value` 或 FDR。
