# CRISPR 基因—基因共依赖分析

## 模块目的

本模块使用 DepMap CRISPR Gene Effect 数据，分析不同细胞系对两个基因敲除的敏感性是否协同变化。正相关表示两种依赖模式相似，常用于发现同一功能通路或复合物成员；负相关表示依赖模式相反。相关性本身不能证明直接调控或合成致死。

## 与 TM00 的关系

TM00 第 03 号脚本先验证 `FOXA1–ESR1`、`SPDEF–ESR1`，再计算 `ESR1–全部基因`，并包含约 1.7 万基因的完整两两相关矩阵。当前 26Q1 实现使用 18,531 个 Gene Effect 基因和 1,208 个细胞系重新构建全局矩阵，并增加癌种谱系内网络。

```text
TM00-03：示例基因对、ESR1 × 全部基因、全基因矩阵
    ↓
26Q1 全局：18,531 × 18,531 个 Gene Effect 基因
    ↓
26Q1 癌种内：每个合格谱系分别计算，按源基因保存正/负相关 Top 100
```

## 样本口径审查结论

当前正式全局矩阵使用全部 1,208 个可用 Gene Effect 细胞系。TM00 脚本 01 会先取 Gene Effect、表达矩阵和 Model 信息的交集，因此脚本 03 实际只使用 1,140 个细胞系。减少的 68 个模型均存在于 Gene Effect 和 Model 数据中，但没有进入构建时冻结的表达默认样本集合。

`ESR1–FOXA1` 的对照结果为：

| 口径 | 样本数 | Pearson r | P 值 |
|---|---:|---:|---:|
| 当前全 Gene Effect 主分析 | 1,208 | 0.3598108 | 3.1201 × 10^-38 |
| TM00 三表交集复现 | 1,140 | 0.3682355 | 6.2618 × 10^-38 |

两个口径均为中等正相关，方向和结论一致。纯共依赖分析以 1,208 个样本为主结果；1,140 个交集样本用于复现 TM00 和敏感性验证。涉及表达—依赖联合分析时必须使用共同细胞系。
