# ESR1–FOXA1 全局共依赖测试记录

测试日期：2026-09-08。

## 测试对象

- 数据：DepMap 26Q1 `CRISPRGeneEffect.csv`
- 分析：全局 Gene Effect 基因—基因 Pearson 相关
- 基因对：`ESR1–FOXA1`

## 结果

| 指标 | 数值 |
|---|---:|
| Pearson `r` | 0.35981081965696626 |
| 共同样本数 `n` | 1,208 |
| 重新计算的 P 值 | 3.1201201506064747 × 10^-38 |
| 方向 | 正相关 |
| 按预设说明的强度 | 中等 |
| ESR1 所在结果分块 | `block_04865_04992.rds` |

该结果表示：跨 1,208 个细胞系，ESR1 和 FOXA1 的 CRISPR Gene Effect 依赖谱呈中等程度正相关。它支持两者依赖模式相似，但不能单独证明直接调控关系。

## 验证

1. 从模块实体结果读取 `ESR1→FOXA1`：`r = 0.35981081965696626`。
2. 反向读取 `FOXA1→ESR1`：数值完全一致，矩阵对称性通过。
3. 从完整 `CRISPRGeneEffect.csv` 的两列重新执行 `cor.test()`：`r = 0.3598108196569664`、`n = 1208`、`p = 3.1201201506063844 × 10^-38`，与落盘矩阵在浮点精度内一致。
4. 从旧兼容路径读取的结果与模块实体路径一致。

查询脚本为 `scripts/query_gene_pair.R`；原始数据复核脚本为 `scripts/validate_esr1_foxa1.R`。

## 与 TM00 原始脚本结果对照

TM00 脚本 01 会先取 Gene Effect、表达矩阵和 Model 信息的细胞系交集。使用落盘结果中冻结的表达 `sample_order.csv` 重建该交集后，共有 1,140 个模型：

| 版本 | 样本数 | Pearson r | df | P 值 |
|---|---:|---:|---:|---:|
| TM00-01 交集口径 | 1,140 | 0.3682355086946435 | 1,138 | 6.261752687197754 × 10^-38 |
| 当前全 Gene Effect 口径 | 1,208 | 0.3598108196569663 | 1,206 | 3.120120150606475 × 10^-38 |

TM00 交集结果与原始 R 控制台截图中的 `r = 0.3682355`、`df = 1138`、95% CI `[0.3169516, 0.4173724]` 完全一致。两套结果使用相同类型的 CRISPR Gene Effect 数据和相同 Pearson 方法；数值差异来自当前全局矩阵额外包含 68 个未进入 TM00 三表交集的 Gene Effect 模型。
