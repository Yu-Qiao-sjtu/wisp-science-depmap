# 分析方法与审查说明

## 全局分析

`04_build_global_correlation_matrices.R --dataset effect` 读取 `CRISPRGeneEffect.csv`，以细胞系为观测维度，计算 18,531 个 Gene Effect 基因的两两 Pearson 相关。结果按 128 个源基因分块保存为 RDS，并保存 `correlation` 与 `pair_n`。

Gene Effect 越负通常表示敲除后细胞生长受损越强。两个基因呈正相关，表示它们在不同细胞系中的依赖谱相似；这可以支持共同功能假设，但不是直接相互作用的证明。

## 癌种谱系内分析

`17_build_lineage_sparse_networks.R --families effect_correlation` 按 `Model.OncotreeLineage` 分组。每个谱系至少需要 10 个共同模型；每个源基因与全部目标基因完成相关计算后，保存正相关 Top 100 和负相关 Top 100，以及 `pair_n`、P 值、BH FDR 和排名，并生成互惠基因对。

未出现在癌种内结果中的基因对只表示未进入 Top 100，不能解释为没有相关性。

## 与表达共相关的区别

- `expression_correlation` 比较两个基因的表达量，回答它们是否共表达。
- `effect_correlation` 比较两个基因的 CRISPR 敲除效应，回答它们是否具有相似的依赖谱。
- 两者使用不同输入、样本规模和生物学含义，应作为两个独立模块审查。

## 审查限制

- 全局相关可能受癌种组成影响。
- 癌种内结果样本更少，效应估计的不确定性更高。
- 大规模检验需要结合效应量、FDR、样本数和跨谱系稳定性。
- TM00 与 26Q1 使用的发布版本和模型集合不同，当前实现属于方法升级，不能宣称逐项数值复现。

## TM00 与当前全局矩阵的样本口径差异

### 差异来源

TM00 脚本 01 在保存 `depmap_geneEffect.rds` 之前执行以下交集：

```r
commonindex <- intersect(rownames(geneEffect), rownames(exprSet))
commonindex <- intersect(commonindex, rownames(cellinfor))
geneEffect <- geneEffect[commonindex, ]
```

因此 TM00 脚本 03 使用的并非全部 Gene Effect 模型，而是同时具有 Gene Effect、表达量和 Model 注释的模型。当前正式全局 `effect_correlation` 只计算 Gene Effect—Gene Effect 相关，不依赖表达量，所以直接使用所有 Gene Effect 模型。

冻结的结果样本清单对比为：

| 集合 | 模型数 |
|---|---:|
| Gene Effect | 1,208 |
| 表达量默认模型 | 1,719 |
| Model 注释 | 2,154 |
| Gene Effect ∩ 表达量 | 1,140 |
| Gene Effect ∩ Model | 1,208 |
| Gene Effect ∩ 表达量 ∩ Model | 1,140 |

从 1,208 减少到 1,140 的 68 个模型都有 Gene Effect 和 Model 注释，但未进入构建时冻结的表达默认模型集合。

### ESR1–FOXA1 对照

| 口径 | n | r | df | P 值 | 95% CI |
|---|---:|---:|---:|---:|---:|
| TM00 三表交集 | 1,140 | 0.3682355087 | 1,138 | 6.2618 × 10^-38 | 0.3169516～0.4173724 |
| 当前全 Gene Effect | 1,208 | 0.3598108197 | 1,206 | 3.1201 × 10^-38 | — |

TM00 交集复算与原始 R 控制台截图中的 `r = 0.3682355`、`df = 1138` 和置信区间完全一致。当前结果的轻微变化来自额外纳入 68 个 Gene Effect 模型，不是相关算法变化。

### 推荐口径

- 纯 Gene Effect 基因—基因共依赖：使用 1,208 个样本作为主分析，充分利用可用 CRISPR 数据。
- TM00 结果复现和稳健性检查：同时报告 1,140 个三表交集样本结果。
- 表达—依赖、多组学联合分析：按 ModelID 取相关数据源的共同样本。

不得把两个样本口径的数值混为同一结果。报告时应明确写出使用的样本集合和 `n`。
