# 输入数据清单

本目录保存完整 26Q1 输入数据实体及其说明。服务器上的文件由构建矩阵时使用的本地完整输入同步而来，并已通过 SHA-256 校验。

| 输入 | 用途 |
|---|---|
| `data/CRISPRGeneEffect.csv` | 行为细胞系，列为基因；用于全局及癌种内共依赖相关 |
| `data/Model.csv` | 用 `ModelID` 对齐细胞系，并通过 `OncotreeLineage` 划分癌种谱系 |
| `TM00/DepMap_TM00/output/depmap_geneEffect.rds` | TM00 第 03 号脚本使用的旧版清洗矩阵 |

26Q1 全局矩阵包含 1,208 个模型和 18,531 个 Gene Effect 基因。脚本会移除列名末尾括号中的 Entrez ID，使用 gene symbol 作为矩阵标识。

完整 `CRISPRGeneEffect.csv` 的 SHA-256 为 `e610a4cefb13a82b5b256b47eb08b63ff14843f8dbd0fb164bc0a32688e5b89e`。`inputs/tm00-3d/` 下的 108 样本裁剪文件属于其他分析，不是本模块全局矩阵的输入。
