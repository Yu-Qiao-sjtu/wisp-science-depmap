# 癌种内突变锚定基因选择：Agent 知识库提示

## 模块标识

- 模块：癌种内突变锚定基因选择
- 数据版本：DepMap Public 26Q1
- 核心对象：`癌种 + 突变基因 + 事件定义`
- 可用事件定义：`AnySelected`、`Damaging`、`Hotspot`、具体 `ProteinChange`
- 下游结果类型：CRISPR Gene Dependency 概率或 Gene Effect；回答时必须写明，不能混用

## 需要识别的用户意图

| 用户表达示例 | 意图 | 默认动作 |
|---|---|---|
| “肺癌可以选哪些突变基因？” | 癌种内锚点发现 | 返回该癌种严格菜单，并分 Damaging/Hotspot 展示 |
| “给我看这个癌种全部突变概况” | 景观浏览 | 返回 AnySelected，并声明不能直接推断功能 |
| “哪些抑癌基因失活后可以分析？” | TSG/LoF 筛选 | 使用 Damaging，核对 Mut/WT 和角色匹配 |
| “有哪些癌基因热点可以分析？” | OG/GoF 筛选 | 使用 Hotspot，核对 Mut/WT 和热点证据 |
| “分析 KRAS G12D” | 特定位点分析 | 使用长表 ProteinChange 精确分组并重新计数 |
| “某突变基因会依赖哪些基因？” | 正向突变—依赖分析 | 先确定事件口径，再从全基因依赖结果排序 |
| “哪些突变让 GPX4 更依赖？” | 反向靶基因查询 | 固定依赖靶基因，再跨突变锚点检索 |
| “没有记录是不是 WT？” | 数据定义解释 | 区分显式矩阵 0、长表无记录和缺失值 |
| “要不要去掉共同必需基因？” | 混杂/过滤解释 | 锚点保留标记；依赖靶点侧降权或敏感性过滤 |

同义表达应覆盖：突变、变异、mutation、mutant、LoF、loss of function、失活、截短、移码、剪接损伤、hotspot、热点、驱动位点、错义、missense、蛋白改变、锚点、固定突变基因、候选基因。

正向和反向是同一张有方向的“突变事件 × 依赖靶基因”关系矩阵的两种查询。正向固定 mutation source，反向固定 dependency target。用户说“热点基因”时必须确认其含义：它可能指带有 Hotspot 标签的突变事件，也可能只是用户关注的核心依赖靶基因；后者不要求具有热点突变。

## 决策规则

1. 先识别癌种、基因、具体位点和研究方向；缺失信息不自行编造。
2. 用户表达“失活、LoF、抑癌基因、截短、移码、剪接损伤”时，首选 Damaging。
3. 用户表达“激活、GoF、癌基因、热点、复发驱动”时，首选 Hotspot。
4. 用户给出蛋白位点时，优先具体 `ProteinChange`，不得退化为整个基因的任意错义集合。
5. 用户只说“某基因突变”时，同时报告 AnySelected、Damaging、Hotspot 的 Mut/WT；说明三者含义后再推荐。
6. `>0` 才是对应矩阵定义下的 Mut；显式 `0` 是未检出该类型；NA/缺失从分组中排除。
7. 标准门槛为 Mut≥3、WT≥5；严格推荐为 Mut≥10、WT≥5。低于门槛时明确回答“当前癌种样本不足”。
8. AnySelected 用于概况和候选发现，不据此声称功能性、驱动性或合成致死。
9. Common Essential 不从锚点菜单中自动删除；在依赖靶点侧提示普遍必需性风险。
10. 每次回答必须写出数据版本、事件定义、癌种、Mut/WT、依赖指标以及已知限制。
11. 已知突变事件、询问“依赖谁”时走正向 source 查询；已知依赖靶基因、询问“哪些突变影响它”时走反向 target 查询；两个实体都给出时走成对验证。
12. 正向和反向的 FDR 家族不同。不得把按某一突变源对全靶点校正的 FDR，冒充按某一靶点对全突变源校正的 FDR。

## 禁止混淆

- 不把 `isDeleterious` 当作当前 26Q1 的正式分组字段。
- 不把 LikelyLoF、Hotspot 和所有错义突变视为互斥类别。
- 不把“长表没有记录”无条件解释成生物学 WT。
- 不把突变记录行数当作突变细胞系数。
- 不把原始脚本的泛癌 Mut≥30 演示门槛当作当前癌种内准入标准。
- 不把 Gene Effect 的负值方向与 Gene Dependency 的 0–1 概率方向混用。
- 不把候选卡片解释成因果或临床证据。

## 推荐回答格式

```text
癌种：{lineage}
候选基因：{gene}
事件定义：{AnySelected / Damaging / Hotspot / ProteinChange}
样本：Mut={mut_n}，WT={wt_n}，是否达到标准/严格门槛
选择依据：{TSG/OG 角色、热点或 LoF 证据、具体位点}
依赖指标：{CRISPR Gene Dependency / Gene Effect}
提示：{Common Essential、组织集中、样本量、证据版本等}
下一步：{正向全基因依赖筛选 / 固定依赖靶点反向查询 / 位点级重算}
```

## 模块事实

- 可分析依赖队列：1,208 个模型、30 个 OncotreeLineage。
- 矩阵规模：Damaging 19,578 个基因；Hotspot 554 个基因；AnySelected 19,784 个基因。
- 基因特征查询优先读取预生成的 `gene_annotation_cache_26Q1/all_mutation_gene_annotations.csv/jsonl`。该缓存一行一个基因，覆盖依赖队列中全部 19,784 个 AnySelected 突变基因；不要为普通用户查询逐基因联网。
- OncoKB 角色空值表示本地角色快照未收录，不等于该基因没有癌症作用。HGNC 未解析符号保留原 DepMap 名称和 `unresolved` 状态，不静默删除或自动猜测。
- 发布长表审计：467,707 条记录；LikelyLoF 82,568 条；Hotspot 2,671 条；二者重叠 1,202 条。
- 知识卡片：完整 54,813 张；严格功能事件 145 张；角色匹配优先卡片 75 张。
- 正式结果只记录模块相对位置；不得向用户输出私有服务器绝对路径。

详细依据和常见问题见 `问题梳理与结论.md` 与 `突变类型与选择指南.md`。
