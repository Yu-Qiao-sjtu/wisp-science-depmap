# PR #6 中文说明：26Q1 癌种内突变锚点与双向依赖分析

## 这个 PR 解决什么问题

固定一个癌种后，研究者需要先知道哪些基因在该癌种中具有足够的突变阳性和阴性细胞系，才能选择合理的突变锚点并继续分析 CRISPR 基因依赖。本 PR 将散落的 06–11 号突变脚本、事件定义、筛选门槛、统计方向和知识卡片整理为一个可复查模块。

模块同时支持两种有方向的查询：

1. 固定突变事件，查找其对应的全基因组依赖差异，例如“ARID1A 损伤性突变后更依赖哪些基因”。
2. 固定依赖靶基因，反查哪些突变事件与该依赖变化相关，例如“哪些突变会让细胞更依赖 PARP1”。

两种查询使用同一张“突变事件 × CRISPR 依赖基因”关系矩阵，但 source 和 target 不可交换。

## 数据口径

- 发布版本：DepMap Public 26Q1。
- 依赖指标：`CRISPRGeneDependency.csv`；高值代表更可能依赖，不能套用 Gene Effect 的负值方向。
- 正式依赖队列：1,208 个细胞系、18,531 个依赖基因。
- 癌种范围：依赖队列中可映射到 Model 注释的 30 个癌种。
- `Damaging`：来自官方 `OmicsSomaticMutationsMatrixDamaging.csv`，依据 LikelyLoF，优先用于抑癌基因和功能丧失问题。
- `Hotspot`：来自官方 `OmicsSomaticMutationsMatrixHotspot.csv`，优先用于癌基因和功能获得问题。
- `AnySelected`：发布突变长表中至少有一条保留记录，只用于查看完整突变概况，不自动等同于功能性突变。
- 矩阵中的 0 表示该发布矩阵未检出相应事件；缺失值不自动作为野生型。

## 锚点筛选规则

对每个癌种、每个突变定义和每个基因分别统计 Mut 与 WT：

- 标准可分析门槛：Mut ≥ 3、WT ≥ 5，用于保留完整候选概况。
- 严格推荐门槛：Mut ≥ 10、WT ≥ 5，用于正式候选菜单。
- 后续每个“突变事件 × 依赖基因”检验还要针对 dependency 缺失重新计算有效 Mut/WT 样本数。
- Common Essential 基因在突变锚点侧保留并标记，不做一刀切删除；在依赖靶基因侧可过滤或作为敏感性分析。
- TSG 优先匹配 Damaging，OG 优先匹配 Hotspot。角色匹配用于排序和解释，不构成功能验证。

筛选过程、公式和边界详见 `锚点基因筛选方法.md` 与 `06-11突变脚本数理逻辑审计.md`。

## 当前已有结果

- 癌种内标准候选：54,813 条。
- 严格候选：3,259 条。
- 完整突变基因注释缓存覆盖 19,784 个基因，其中 19,775 个解析到 HGNC，9 个保留原始 DepMap 符号并标记为 unresolved。
- 知识卡片分为完整卡片、严格功能候选和优先候选，用于解释“为什么这个癌种可以选择这个突变基因”。
- Damaging × Gene Dependency 全量概率与正式统计已经完成；Hotspot × Gene Dependency 全量概率和具体 ProteinChange × Dependency 仍是后续工作。

这些结果表示样本可分析性、事件定义和统计关联，不证明突变导致某个依赖，也不直接等同于合成致死关系。

## 06–11 号脚本分工

| 脚本 | 作用 | 在当前模块中的定位 |
| --- | --- | --- |
| 06 | 癌种内突变锚点候选选择 | 确定“这个癌种有哪些突变基因可以选” |
| 07 | 突变组与 WT 组的依赖差异 | 正式 Welch 检验、效应量与方向内 BH FDR 核心 |
| 08 | 从突变长表重建或核对事件矩阵 | 事件定义审计，不替代官方矩阵 |
| 09 | 固定突变事件查依赖靶基因 | 正向探索接口 |
| 10 | 固定突变事件并限制癌种 | 癌种内正向探索接口 |
| 11 | 固定依赖靶基因反查突变事件 | 癌种内反向探索接口 |

原始脚本快照保存在 `scripts/tm00-reference/`，并用 `source_manifest.json` 固定文件大小和 SHA-256，供历史追溯。新分析以模块当前脚本和 `module.intent.json` 为准。

## 公开仓库边界

仓库保存：

- 可复现脚本和统计契约；
- 中文方法说明与用户意图路由；
- 小型 CSV/JSON 审计汇总；
- 原始 06–11 号脚本的校验快照。

仓库不保存：

- 约 180 GB 的 DepMap 原始数据和大型中间矩阵；
- 服务器地址、用户名、绝对目录和访问凭据；
- 大型全量结果文件；
- 任何需要通过服务器权限控制的私有材料。

大型数据与结果继续保存在受权限控制的计算环境中，仓库文档仅使用模块相对路径描述它们。

## 审查入口

建议按以下顺序审查：

1. `README.md`：模块入口和文件索引。
2. `锚点基因筛选方法.md`：候选基因如何产生。
3. `突变类型与选择指南.md`：Damaging、Hotspot 和具体突变类型如何选择。
4. `突变依赖双向分析与脚本索引.md`：正向与反向查询如何映射到脚本。
5. `06-11突变脚本数理逻辑审计.md`：统计公式、风险与统一执行规范。
6. `module.intent.json`：供 Agent 使用的机器可读意图契约。
