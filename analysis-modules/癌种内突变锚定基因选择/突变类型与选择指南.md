# 26Q1 突变类型与锚定基因选择指南

## 三层数据含义

1. `AnySelected`：`OmicsSomaticMutations.csv` 发布长表中至少有一条记录。它是经过 DepMap 质量过滤和癌症相关 rescue 的体细胞点突变/小 indel 集合，不是未经筛选的全部原始变异，也不说明功能方向。
2. `Damaging`：官方 `OmicsSomaticMutationsMatrixDamaging.csv`。变异满足 `LikelyLoF=True` 后按模型和基因聚合；适合抑癌基因及功能丧失假设。
3. `Hotspot`：官方 `OmicsSomaticMutationsMatrixHotspot.csv`。依据 Hess、OncoKB、COSMIC Tier 1、TERT 启动子和 MET 特定区域等热点标准聚合；适合癌基因和复发性驱动事件。

三者不是互斥分类。一个变异可以同时属于 Damaging 和 Hotspot。矩阵值 1/2 表示至少有一个符合定义的变异及聚合等位基因频率层级，不能直接证明单/双等位功能状态。

## 26Q1 实际数据概况

`scripts/audit_mutation_types_26Q1.R` 在能够进入 Gene Dependency 分析的 1,208 个默认细胞系中审计了发布长表。结果保存在服务器模块的 `mutation_type_audit_v1/`：

- 保留 467,707 条变异记录，覆盖 19,784 个基因、16 类主要 VEP consequence。
- `missense_variant` 共 381,607 条，是数量最多的一类。错义数量多只表示变异后果为氨基酸替换，不能据此判断它是驱动、功能获得或功能丧失。
- `LikelyLoF=True` 共 82,568 条，其中 1,202 条同时也是 Hotspot。
- `Hotspot=True` 共 2,671 条；热点是证据标签，不等同于全部错义突变。
- 其他主要类型包括移码、终止获得、剪接受体/供体、框内缺失/插入、起始丢失和终止丢失。

这些数字统计的是 DepMap 已发布并经过过滤或 rescue 的变异记录，不是测序产生的全部原始 variant call。一个模型—基因也可能有多条记录，因此“变异行数”和“模型—基因事件数”不能混用。

## 长表中的常见后果

`VariantInfo`/VEP consequence 可包含 `missense_variant`、`frameshift_variant`、`stop_gained`、`splice_acceptor_variant`、`splice_donor_variant`、`inframe_deletion`、`inframe_insertion`、`start_lost`、`stop_lost` 等。错义突变的功能差异很大：普通错义不能自动等同于功能获得、功能丧失或驱动突变。需要结合 Hotspot、OncoKB/CIViC 等位点证据或明确的蛋白变化。

## 选择规则

| 用户问题 | 首选事件定义 | 说明 |
|---|---|---|
| 某抑癌基因失活后依赖谁 | Damaging | 先看 TSG/LoF 角色匹配及癌种内 Mut/WT 数量 |
| 某癌基因激活后依赖谁 | Hotspot | 先看 OG/GoF 角色及热点位点证据 |
| 想看该癌种全部突变概况 | AnySelected | 用于发现和浏览，不能直接进入功能结论 |
| 研究一个具体错义位点 | 长表中的 `HugoSymbol + ProteinChange` | 必须按具体位点分组；不能把同一基因的所有错义变异混为同一种功能 |
| 研究截短/剪接/移码事件 | 长表 consequence 或 Damaging | 若目标是复现官方 LoF，优先 Damaging；自定义分类必须另命名并记录规则 |

推荐卡片优先级还应考虑：癌种内有效 Mut/WT 数量、TSG/OG 与事件定义是否匹配、是否为已知驱动、突变是否集中于单个位点、是否受超突变样本/大基因乘客效应影响。Common Essential 只标记，不在突变锚点侧自动删除；在后续依赖靶点排序中用于降低普遍毒性靶点的优先级。

## 给用户展示什么

每张候选卡片至少显示：癌种、基因、事件定义、Mut/WT 数量、频率、主要 consequence、是否 LikelyLoF、是否 Hotspot、TSG/OG 角色、Common Essential 标记和数据版本。界面中的“突变”必须带上口径，例如“TP53 Damaging”或“KRAS Hotspot”，不能只写“TP53 突变”。

可以按用户意图这样解释和触发：

- “查看这个癌种有哪些突变基因”或“全部突变概况”：返回 `AnySelected`，并提示这是发现层。
- “找抑癌基因失活”“LoF”“截短/移码/剪接损伤”：优先 `Damaging`。
- “找癌基因激活”“驱动热点”“复发位点”：优先 `Hotspot`。
- “分析 KRAS G12D”“某个错义位点”：从长表按 `HugoSymbol + ProteinChange` 精确分组，并重新计算该位点的 Mut/WT；不能直接套用基因级矩阵。
- 用户只说“某基因突变”且功能问题不明确时，同时展示 Damaging、Hotspot 和 AnySelected 的样本数，让用户根据机制假设选择，不由模型暗中合并。

## 当前结果边界

- 当前 Damaging、Hotspot 与按需 ProteinChange 的默认正式分析统一使用 `CRISPRGeneEffect.csv` 连续分数，并用 `CRISPRGeneDependency.csv` 概率计算依赖比例。
- 旧的概率连续分析与既有 Gene Effect 大矩阵保留追溯，但不能与 `depmap_official_gene_effect_v2` 混称为同一统计版本。
- `custom_missense_mutation_dependency` 实际合并九类蛋白改变事件，并非纯错义分析；后续应更名为“自定义蛋白改变事件”，或为具体错义位点建立独立分析。
- 知识卡片必须保留数据版本、事件定义、样本数和证据来源；大语言模型只解释已有字段，不自行推断某变异的功能方向。
