# TM00 06–11 原始脚本快照

这里保存本模块审计时使用的六个 TM00 26Q1 原始脚本快照，使文档中的公式和结论可以在项目内直接追溯。源目录中的原文件继续保留，避免破坏既有手工运行入口。

这些文件记录原始探索过程，不代表当前推荐执行入口：

- 06 的锚点选择由上级目录的 `run_anchor_gene_selection_26Q1.R` 扩展为全基因、分事件的正式菜单。
- 07 的 Welch 检验和双向 BH FDR 是正式统计基础，但执行时必须按每个突变—靶点对重新计算完整观测人数。
- 08 用于审计 AnySelected、Damaging、Hotspot 和自定义九类蛋白改变事件。
- 09–11 的乘积 Score 仅用于理解旧图和探索性排序，不作为显著性证据。

逐脚本数理解释见模块根目录的 `06-11突变脚本数理逻辑审计.md`。文件身份见 `source_manifest.json`。
