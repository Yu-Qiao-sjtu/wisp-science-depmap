# 癌种内突变锚点基因筛选方法

## 1. 筛选目的

本流程回答：在指定癌种内，哪些突变基因和突变事件具有足够的 Mut/WT 细胞系，可以作为后续 CRISPR 基因依赖分析的锚点。

筛选结果表示“具备后续分析条件”，不表示该突变已经影响某个依赖靶基因，也不表示已经发现合成致死或临床标志物。

## 2. 数据版本与输入

数据版本固定为 DepMap Public 26Q1。

| 输入 | 用途 |
|---|---|
| `Model.csv` | 提供 ModelID 和 `OncotreeLineage` 癌种注释 |
| `CRISPRGeneEffect.csv` / `CRISPRGeneDependency.csv` | 前者用于正式连续差异检验，后者用于靶点预筛和依赖比例 |
| `OmicsSomaticMutationsMatrixDamaging.csv` | 提供官方 LikelyLoF 聚合的基因级 Damaging 事件 |
| `OmicsSomaticMutationsMatrixHotspot.csv` | 提供官方热点证据聚合的基因级 Hotspot 事件 |
| `OmicsSomaticMutations.csv` | 提供 AnySelected 景观和具体 `ProteinChange` 信息 |
| `CRISPRInferredCommonEssentials.csv` | 标记共同必需基因，不在突变锚点侧自动删除 |
| HGNC 本地表 | 标准基因符号、名称、类型和历史符号映射 |
| OncoKB 派生本地表 | 提供 TSG/OG 角色参考；空值表示本地快照未分类 |

## 3. 建立可分析模型队列

每一种突变事件来源分别建立自己的队列：

```text
Damaging cohort = Model ∩ Gene Dependency ∩ Damaging matrix
Hotspot cohort  = Model ∩ Gene Dependency ∩ Hotspot matrix
AnySelected cohort = Model ∩ Gene Dependency ∩ released mutation table
```

交集使用 `ModelID`。不要求 Damaging、Hotspot 和 AnySelected 彼此再取共同交集，因为一种事件的数据覆盖不应限制另一种事件。

26Q1 实际结果：

- Model 注释：2,154 个模型；
- Damaging 默认模型：1,968 个；
- Hotspot 默认模型：1,968 个；
- Gene Dependency 模型：1,208 个；
- 三种事件进入当前菜单的可分析模型均为 1,208 个；
- `OncotreeLineage` 共覆盖 30 个癌种。

当前 Damaging 和 Hotspot 默认模型集合恰好相同，但流程仍保持事件来源独立，以适应后续 DepMap 发布变化。

## 4. 突变事件定义

设细胞系为 \(i\)，基因事件为 \(e\)，事件状态记为 \(M_{ie}\)。

### 4.1 Damaging

```text
Damaging matrix > 0 → Mut
Damaging matrix = 0 → WT
Damaging matrix缺失 → Unknown，排除
```

Damaging 来源于 DepMap 26Q1 的 LikelyLoF 聚合，优先用于抑癌基因和功能丧失假设。矩阵值 1 或 2 都归为事件阳性；这里不把 2 自动解释为已经证明的双等位完全失活。

### 4.2 Hotspot

```text
Hotspot matrix > 0 → Mut
Hotspot matrix = 0 → WT
Hotspot matrix缺失 → Unknown，排除
```

Hotspot 优先用于癌基因、复发热点和功能获得假设。Hotspot 与 Damaging 可以重叠，不是互斥分类。

### 4.3 AnySelected

在完整可分析模型集合中，若发布长表存在该模型—基因的保留变异记录，则记为 AnySelected 阳性；没有对应记录表示“在当前发布表中未观察到入选记录”。

AnySelected 用于回答“这个癌种有哪些基因发生过发布变异”，不直接赋予损伤性、驱动性或功能性含义。

### 4.4 ProteinChange

用户指定 KRAS G12D、BRAF V600E 等具体位点时，从长表按 `HugoSymbol + ProteinChange` 建立事件。位点级事件不预先遍历全部组合，在用户选择后重新计算 Mut/WT。

## 5. 癌种内计数

对癌种 \(l\) 和事件 \(e\)，只使用事件状态明确且具有癌种注释的模型：

\[
n_{Mut}(e,l)=\sum_i I(L_i=l\;\land\;M_{ie}=1)
\]

\[
n_{WT}(e,l)=\sum_i I(L_i=l\;\land\;M_{ie}=0)
\]

\[
n_{Unknown}(e,l)=\sum_i I(L_i=l\;\land\;M_{ie}=NA)
\]

缺失状态不得加入 WT。突变记录行数也不得当成突变细胞系数；同一模型同一基因的多条记录最终只贡献一个事件状态。

## 6. 样本量门槛

| 层级 | 门槛 | 用途 |
|---|---|---|
| 完整景观 | 不设功能性门槛 | 查看癌种内全部 AnySelected 概况 |
| 标准候选 | Mut≥3、WT≥5 | 建立可浏览、可进一步评估的候选菜单 |
| 严格候选 | Mut≥10、WT≥5 | 选择更适合癌种内后续验证的锚点 |
| 新版正式依赖检验 | 完整观测后 Mut≥5、矩阵阴性≥5 | 进入每一个突变—依赖靶点的官网方法适配检验 |

3/5 和 10/5 是锚点选择门槛，不是突变的生物学定义，也不是统计显著性。正式依赖检验会因为不同靶基因的 Dependency 缺失情况而重新计算有效 Mut/WT，不能直接复用锚点菜单人数。

## 7. 生物学角色匹配

达到样本门槛后，再使用本地 HGNC 与 OncoKB 派生角色提高优先级：

| 基因角色 | 优先事件 | 理由 |
|---|---|---|
| TSG/抑癌基因 | Damaging | 与功能丧失假设一致 |
| OG/癌基因 | Hotspot | 与复发激活或功能获得假设一致 |
| 同时具有 TSG 和 OG 角色 | Damaging、Hotspot 分开保留 | 两种机制不能合并成一个“任意突变”事件 |
| 本地角色未分类 | 保留在完整菜单 | 未分类不等于没有癌症意义 |
| 指定蛋白位点 | ProteinChange | 直接对应等位基因机制 |

角色匹配只用于候选排序和解释，不替代 Mut/WT 依赖差异检验。

## 8. Common Essential 的处理

共同必需基因不会从突变锚点侧自动删除，原因是 KRAS、PIK3CA、VHL、BRCA2 等癌症相关基因也可能出现在 Common Essential 表中。删除它们会丢失有意义的突变来源。

处理规则：

- 突变锚点侧：保留并添加 `is_common_essential` 标记；
- 依赖靶点侧：提示普遍生存效应，可降权、过滤或进行敏感性分析；
- 同时输出保留版和排除共同必需基因后的敏感性汇总。

不使用“是否可成药”作为删除突变锚点的条件。

## 9. 输出层级

| 输出 | 记录内容 | 当前规模 |
|---|---|---:|
| `gene_by_lineage_mutation_menu` | 所有癌种×基因×事件的 Mut/WT 计数 | 791,886 条 |
| `candidate_anchor_genes_by_lineage` | 达到标准 3/5 门槛的候选 | 54,813 条 |
| `selectable_anchor_genes_by_lineage` | 达到严格 10/5 门槛的候选 | 3,259 条 |
| 严格功能事件卡片 | 严格候选中的 Damaging/Hotspot 卡片 | 145 张 |
| 角色匹配优先卡片 | 严格且满足 TSG–Damaging 或 OG–Hotspot | 75 张 |
| 全基因注释缓存 | 突变宇宙中的一行一个基因注释 | 19,784 个基因 |

这些数字中的“条”表示癌种×基因×事件记录，不等于唯一基因数；同一基因可以在多个癌种和多个事件口径中出现。

## 10. 候选等级

建议按以下顺序展示：

1. **优先锚点**：严格门槛通过，且基因角色与事件定义匹配；
2. **严格可分析**：严格门槛通过，但本地角色未分类或机制仍需确认；
3. **标准探索**：达到 3/5，适合浏览和生成假设；
4. **景观记录**：仅 AnySelected 或低于标准门槛，用于完整概况；
5. **当前不可分析**：Mut<3 或 WT<5，明确报告样本不足。

## 11. 从锚点进入依赖分析

选择锚点后，针对每个依赖靶基因 \(g\) 重新构建完整观测集合，并计算：

\[
\Delta_{eg}=mean(Y_g\mid Mut_e)-mean(Y_g\mid WT_e)
\]

新版正式结果使用 Gene Effect，\(\Delta<0\) 表示突变组更依赖；报告有效 Mut/矩阵阴性人数、两组均值、差值、95% 置信区间、双侧等方差 t 检验 P 值和按锚点 BH FDR。Gene Dependency 概率只用于依赖比例与优势比。

锚点菜单本身不能支持以下表述：

- “这个突变导致某基因依赖”；
- “已经发现合成致死”；
- “该突变是癌种特异标志物”；
- “可以直接指导临床用药”。
