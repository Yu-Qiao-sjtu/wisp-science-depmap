# 2D True Love Gene 与 TM00 原脚本交叉验证

日期：2026-08-31  
服务器：`guotosky`，账号 `gz0548`

## 结论

原先的 `110` 个高置信配对不是 TM00 原脚本 17 的直接复现结果，而是基于其“双极依赖”思路构建的全基因组扩展，再经过样本量、双向 FDR、相关阈值、完整覆盖和 bootstrap 稳定性过滤得到的单一随机种子结果。

计算本身没有发现列错位、相关系数错误或示例对丢失。500-bootstrap 双 seed 校准后分别得到 108 和 115 对，两次共同通过 105 对，Jaccard 从 100-bootstrap 的 0.7734 提高到 0.8898。因此应把 105 对视为当前跨种子复现核心集合，把其余 13 对标记为边界候选，而不是确定的高置信结果。

## TM00 原脚本实际做了什么

参考文件：`17_bipolar_dependency_ASB7_as_example.R`。

原脚本：

- 从 26Q1 `CRISPRGeneEffect.csv` 读取 1,208 个模型和 18,531 个基因；
- 直接计算 ASB7/SUV39H1、TP53/MDM2 的 Pearson 相关；
- 对 ASB7 和 SUV39H1 分别计算全基因相关并绘图；
- 从各自最负相关 Top 10 出发做有限递归搜索；
- 不生成全基因组严格互为 rank-1 配对全集；
- 不执行双向 BH FDR 筛选；
- 不执行 bootstrap 稳定性分析。

所以原脚本不存在可与 `510` 或 `110` 直接逐项比较的参考总数。

## 我们的扩展定义

基础配对要求：

1. Pearson Gene Effect 负相关；
2. 每个方向至少 500 个共同有效模型；
3. A 的最负相关合格基因是 B，且 B 的最负相关合格基因是 A；
4. 两个方向分别在该 source gene 的合格目标中做 BH 校正。

稳定性层进一步要求：

- 两方向全数据相关均不高于 `-0.20`；
- 两方向 FDR 均不高于 `0.05`；
- 两个基因在全部 1,208 个模型中完整覆盖；
- 随机抽取 80% 模型后，互为最负相关 rank-1 的比例不低于 `0.70`；校准阶段比较 100 次与 500 次重采样。

## 基础一致性检查

- 原始 CSV 基因列数：18,531；
- `effect_correlation/gene_order.csv` 基因数：18,531；
- 两者列顺序完全一致，错位数为 0；
- 独立从 CSV 重算的示例相关系数与预计算 block 完全一致：
  - ASB7/SUV39H1：`r = -0.2054479`，`n = 1208`；
  - CCNF/E2F1：`r = -0.3390032`，`n = 1208`；
  - TP53/MDM2：`r = -0.7177520`，`n = 1208`。

## 原脚本的稀疏样本风险

若完全照原脚本直接对所有列调用 `cor.test` 并排序，会出现只有 4–5 个共同有效模型但绝对相关接近 1 的基因，例如 `ERVV-1`、`RFPL4AL1`、`VCX2`。它们会挤到负相关排名前面，使示例对不再是 rank-1。

这不是预计算矩阵错误。block 中同时保存了这些相关值及其实际 `pair_n`。我们的全基因组扩展通过 `pair_n >= 500` 排除了这种小样本极端相关，这是必要的质量控制，但也意味着扩展定义与原脚本的无门槛排序并不相同。

## 过滤计数

- 严格互为 rank-1 配对：510；
- 同时满足两方向 `r <= -0.20`：454；
- 两基因均完整覆盖并进入 bootstrap：397；
- seed 2601、100 次 bootstrap、稳定性阈值 0.70：110；
- seed 2602、相同其他参数：117。
- seed 2601、500 次 bootstrap：108；
- seed 2602、500 次 bootstrap：115。

## 跨种子复算

- 两次都通过：99；
- 至少一次通过：128；
- Jaccard：`99 / 128 = 0.7734`；
- 397 个候选的两次稳定性分数 Pearson 相关：`0.9668`；
- 平均绝对差：`0.0475`；
- 最大绝对差：`0.23`；
- 阈值分类不一致：29 对。

多数不一致配对靠近 0.70 阈值，例如一次为 0.69、另一次为 0.70。说明硬阈值加 100 次重采样会产生约一个百分点分辨率下的边界波动。

500-bootstrap 结果：

- 两次都通过：105；
- 至少一次通过：118；
- Jaccard：`105 / 118 = 0.8898`；
- 阈值分类不一致：13 对。

增加到 500 次后跨 seed 一致性明显改善，支持增加重采样次数；剩余不一致仍应作为阈值边界不确定性保留，而不能通过挑选某个 seed 消除。

## 示例对

- ASB7/SUV39H1：两次稳定性分别为 `0.82`、`0.89`，均通过；
- CCNF/E2F1：两次均为 `1.00`，均通过；
- TP53/MDM2：两次均为 `1.00`，均通过。

ASB7/SUV39H1 和 TP53/MDM2 可直接关联到 TM00 脚本 17 的示范分析。CCNF/E2F1 是扩展结果中的额外验证对，不应表述为原脚本 17 明示的参考对。

## 建议

1. 不要把任一单 seed 结果命名为最终稳健全集。
2. 当前可报告的核心集合使用 500-bootstrap 两次都通过的 105 对，并保留 seed、阈值和输入版本。
3. 对 13 个跨阈值配对标记为 `borderline_seed_sensitive`。
4. 正式报告应同时给出稳定性比例的区间估计，而不只用单点 `>= 0.70`。
5. 在 manifest 中明确记录 `pair_n >= 500` 是相对 TM00 原脚本新增的质量控制。
6. 把 TM00 复现验证与全基因组扩展验证分开：前者验证示例相关系数和方向，后者验证全局排名、FDR、覆盖率及重采样稳定性。

## 审计产物

原结果位于私有知识库的 `high_confidence_stability` 层；100-bootstrap 独立 seed 结果和两个 500-bootstrap 结果均保存在知识库 `audits/` 的隔离目录下，没有覆盖 canonical 结果。
